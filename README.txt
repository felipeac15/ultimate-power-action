ULTIMATE POWER AUCTION — PRIME BATTLE v9

LANCER LE JEU
- Ouvre index.html dans un navigateur, ou publie le contenu du dossier sur GitHub Pages.
- Pour installer sur iPhone : ouvre l'URL HTTPS dans Safari > Partager > Sur l'écran d'accueil.

NOUVEAUTÉS
- Les notes de puissance ne sont plus affichées pendant les enchères.
- Enchères corrigées avec budget et équipes de 4 ou 5 personnages.
- Les personnages connus ont des profils internes séparés (puissance, vitesse, technique, capacités spéciales, jeu d'équipe).
- Une simulation de combat est lancée après le draft; les éliminations et le rapport de combat sont affichés.
- PWA avec manifeste et service worker.

IMPORTANT
- Les profils de puissance et le résultat du combat sont une simulation de jeu, pas une vérité officielle ou une comparaison canonique entre univers.
- Le multijoueur synchronisé entre téléphones n'est pas activé dans cette archive : il faut connecter un backend temps réel (par exemple Firebase) et fournir sa configuration. Le jeu actuel fonctionne en local sur un seul appareil.
- Les profils PRIME sont des évaluations internes conçues pour le gameplay. Les personnages/versions peuvent varier selon les œuvres et leur canon.
