Ultimate Power Auction — PWA

Le dossier contient le jeu et les fichiers PWA.

Publication :
1. Publie tout le contenu de ce dossier sur un hébergement HTTPS, par exemple GitHub Pages.
2. Ouvre l'adresse publiée sur ton téléphone.
3. iPhone : Safari > Partager > Sur l'écran d'accueil.
4. Android : Chrome > menu ⋮ > Installer l'application ou Ajouter à l'écran d'accueil.

L'installation PWA nécessite HTTPS (ou localhost pour les tests).
