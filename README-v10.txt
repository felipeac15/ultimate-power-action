ULTIMATE POWER AUCTION — PRIME BATTLE v10

Correction: the power meter / points display has been removed from the auction screen. Internal PRIME stats are still used only by the combat simulation.

To update GitHub Pages:
1. Upload and replace index.html, script.js, style.css, manifest.webmanifest, and service-worker.js at the repository root.
2. Keep README.md if you already have one. Do not upload index_old.html or old.js.
3. Commit changes.
4. Open the website and refresh. If an installed PWA still shows old content, close it fully and open the GitHub Pages URL in Safari/Chrome once to let the new service worker update.

Note: this build is still local play on one device. Online multiplayer has not been connected/configured.
